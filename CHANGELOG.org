#+title: Changelog

* Unreleased

** Breaking Changes

- Replaced =vulpea-directory= with =vulpea-default-notes-directory= for journal file path resolution. If you previously set =vulpea-directory=, use =vulpea-default-notes-directory= instead (which defaults to the first entry in =vulpea-db-sync-directories=).

** Fixed

- Fix journal entries not found after database rebuild (=vulpea-db-sync-full-scan=). The journal was using =vulpea-directory= for path computation while the sync system used =vulpea-db-sync-directories=, causing path mismatches in the database lookup. ([[https://github.com/d12frosted/vulpea-journal/issues/5][#5]])
- Fix stale database connections in tests by properly closing connections between test runs.

* v1.0.1 (2026-01-31)

** Changed

- Use =vui-muted= semantic component for de-emphasized text.

** Fixed

- Pass missing prompt argument to =vulpea-journal--read-date= in sidebar date picker.
- Use string keys for property alist lookups in Created Today and Previous Years widgets.
- Update =vulpea-ui= version requirement in =Package-Requires= to 1.0.0.

* v1.0.0 (2026-01-12)

Initial stable release.

** Features

- Daily journaling with one file per day, automatically created with customizable templates
- Seamless integration with [[https://github.com/d12frosted/vulpea-ui][vulpea-ui]] sidebar
- Reactive widgets built on [[https://github.com/d12frosted/vui][vui.el]]:
  - *Navigation* - prev/today/next buttons for quick navigation between journal entries
  - *Calendar* - monthly view with entry indicators, click to jump to any date
  - *Previous Years* - "on this day" view showing entries from past years with preview
  - *Created Today* - notes created on the current journal date
- Customizable templates for file paths and titles
- Automatic widget registration with vulpea-ui
- Sidebar keybindings for quick journal navigation: =[= (previous), =]= (next), =t= (today), =d= (pick date)
- =vulpea-journal-calendar-mode= minor mode for calendar integration, providing idiomatic keybindings that can be toggled
- Migration script in README to help users add =:ID:= and =CREATED= properties to existing journal files

** Performance

- Optimized database queries using indexed lookups (=vulpea-db-query-by-file-path=, =vulpea-db-query-by-created-date=)
- Memoized calendar entry queries
- Disabled button tooltips for faster rendering

** Requirements

- Emacs 29.1+
- vulpea 2.0+
- vulpea-ui 1.0+
- dash 2.20+
